# Surgical Consent Form Generator

A bilingual (Nepali / English) surgical consent form that fills in live as you type and prints on A4. Built as a learning and portfolio project.



## The problem
Paper consent forms are filled in by hand, which is slow and often hard to read. This tool lets staff type the details once and print a clean, consistent form in Nepali, English, or both.

## Features
- Live preview: text appears on the form as it is typed
- Nepali, English, or Nepali + English on the same form
- Patient details, procedure, surgeon, physician / MO, referring hospital, and a date picker
- Five numbered consent clauses (surgery, anaesthesia, blood, emergency procedures) with the surgeon's name filled in automatically
- Signature lines for patient or guardian, witness, and doctor
- Print-ready A4 layout
- Runs in the browser. No data is saved or sent anywhere

## Built with
HTML, CSS and JavaScript, with no frameworks

## Files
- index.html: page structure
- style.css: layout and print styles
- script.js: live preview, language switch and printing

## How to run
Download the files into one folder and open index.html in a browser.

## Important note
The consent wording is sample text. A qualified doctor must review and approve it, in every language, before it is used with patients.
